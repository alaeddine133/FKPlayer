# FK PLAYER

Lecteur IPTV pour box **Android TV / Fire TV**, pilotable à la télécommande.

## Installer avec Downloader
Dans l'appli **Downloader**, tape :

```
https://github.com/alaeddine133/FKPlayer/raw/main/FKPlayer.apk
```

## Fonctions
- Connexion **Xtream Codes** ou **lien M3U**
- Direct avec aperçu vidéo et guide TV (en cours / ensuite)
- Films et séries avec reprise de lecture, épisode suivant automatique
- Ma liste (favoris), recherche instantanée
- Lecteur ExoPlayer : zapping, n° de chaîne, pistes audio, sous-titres, format d'image, reconnexion automatique
- Catégories françaises en premier

Android 5.0 et plus.
